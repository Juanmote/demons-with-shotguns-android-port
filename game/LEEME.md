# Archivos del juego

Esta carpeta está vacía a propósito: aquí van los archivos de **tu** copia de Steam de
Demons with Shotguns, y **solo en tu copia privada** de este repositorio.

Sube un `.zip` o `.7z` con el contenido de la carpeta del juego de Steam
(la que tiene `dws.exe` y la carpeta `dws_Data`). Si pesa más de 25 MB, la web de GitHub
no te dejará subirlo aquí: usa una release con la etiqueta `juego` (ver README).
